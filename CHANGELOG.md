# Change Log

All notable changes to the "Spectra Noir" extension will be documented in this file.

## [1.0.1] - 2026-11-14

- Re-bundled by Winstead-Inc with updated active color settings.
- Refined terminal colors: ANSI cyan (`#7100FF`), yellow (`#3D5AFE`), magenta (`#7100FF`), and bright green (`#15FF00`).
- Updated rainbow bracket pair & indent guide tier 3 accent to `#0077e6`.
- Integrated active TextMate syntax rules for bold keywords, functions, types, JSON keys, and markdown headings.

## [1.0.0] - 2026-11-09

- Initial release of Black Void by Winstetad-Inc.
- Re-architected color palette with deep black foundations and signature purple accents.
- Full 6-tier harmonized rainbow braces, bracket pair guides, and indentation guides.
- High-contrast syntax tokens and unified terminal palette.
